# DCM

在DCM下存在`DcmConfigSet`

## DcmConfigSet

| 容器名称             | 中文直译/惯称                                              | 核心功能职责                                                 | 关键配置内容举例                                             |
| :------------------- | :--------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **DcmGeneral**       | 通用配置                                                   | 配置 DCM 模块的**全局性**、**基础性**参数，是整个模块运行的基础。 | 模块主开关、开发错误检测开关（`DcmDevErrorDetect`）、最大并发会话数、P2/P2* 服务器时间等。 |
| **DcmDsd**           | 诊断服务分发单元<br>（Diagnostic Service Dispatcher）      | 负责**路由和分发**收到的诊断请求。它根据请求报文的第一个字节（SID，Service Identifier）找到对应的处理函数。 | 定义每个 **SID（服务ID）** 由哪个子模块（DSP或DSL）处理，配置分发路由表。 |
| **DcmDsl**           | 诊断会话层<br>（Diagnostic Session Layer）                 | 负责管理诊断**通信的会话状态**和**时序控制**。它是诊断协议栈的“交通警察”。 | 配置**会话状态**（默认、编程、扩展会话）的切换逻辑；配置**安全访问**（Security Access）的种子/密钥算法；配置 **P2/P2\*** 等时间参数。 |
| **DcmDsp**           | 诊断服务处理单元<br>（Diagnostic Service Processing Unit） | 负责实现**具体的诊断服务功能**。这是 DCM **最核心、最庞大**的配置区域。 | 为每个支持的 UDS 服务（如 `0x10`，`0x22`，`0x2E`，`0x31`）定义其**子服务**和具体**行为**，例如：<br>- `0x22`（读数据）需配置其支持的 **DID（数据标识符）** 列表。<br>- `0x31`（例程控制）需配置支持的 **RID（例程标识符）** 及其启动/停止/结果回调函数。 |
| **DcmMiscellaneous** | 杂项配置                                                   | 用于存放 DCM 模块中**不属于上述主要分类**的其他配置参数，通常是些零散的辅助功能。 | 配置 **NRC（否定响应码）** 的抑制行为（例如：在特定条件下是否发送 NRC）、配置诊断请求的**接收超时**处理、或其他特殊功能的开关。 |
| **DcmPageBufferCfg** | 页缓冲区配置                                               | 专门用于配置 DCM 模块的**页缓冲（Page Buffer）** 机制，主要服务于诊断刷写（Flash Over-the-Air, FOTA）场景。 | 页缓冲区的大小、数量、启用/禁用开关（`DcmPageBufferEnabled`）。**注意**：这是“总开关”，开启后才能在此基础上做更详细的页设置。 |



### 💡 补充说明

*   **主从关系**：`DcmDsd` 收到请求后，会将任务分发给 `DcmDsl`（负责会话/安全）或 `DcmDsp`（负责执行具体服务）。`DcmGeneral` 为所有这些子模块提供全局参数。
*   **关键性排序**（按配置复杂度）：
    1.  **DcmDsp**：配置工作量最大，因为每个服务的每个子服务都需要详细定义。
    2.  **DcmDsl**：安全访问和会话管理的配置逻辑较为复杂。
    3.  **DcmGeneral / DcmDsd**：通常配置完成后很少改动。
    4.  **DcmPageBufferCfg**：仅在需要刷写功能时配置，相对独立。
    5.  **DcmMiscellaneous**：作为补充，配置量最小。
